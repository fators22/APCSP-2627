Unit 2: Decisions, Errors, and Testing

Make programs that decide what to do, then find errors and test that code works. Lesson files are in the Unit 2 Google Drive folder.

Learning goals

  • Write Boolean expressions with relational operators (>, <, >=, <=, ==, !=).
  • Store an answer in a Boolean variable and use it in an if.
  • Write if, else if, and else, including nested conditionals.
  • Combine conditions with &&, ||, and !.
  • Use %, frameCount, and random() in decisions.
  • Trace code to predict values and find logic errors.
