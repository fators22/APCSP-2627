Read page 1 before class

One loop draws a row. Put that whole loop inside another loop and you get a grid: for each row, for each column, draw one thing. Keep this beside you while you build; leave page 2 face-down until after.

A loop inside a loop NESTED

for (let r = 0; r < 8; r++) {      // each row
  for (let c = 0; c < 16; c++) {   // each column
    circle(100 + c * 40, 100 + r * 40, 20);
  }
}

Two loops, two names

DO NOT REUSE iAn inner let i hides the outer one, so you can only use one of them. Use r and c (or i and j). Then 100 + c * 40, 100 + r * 40 says what it means.

Build it one row first TODO 1 → 2

// 1. one row that works
for (let c = 0; c < COLS; c++) {
  circle(LEFT + c * SP, TOP, 20);
}
// 2. wrap it; only y changes
for (let r = 0; r < ROWS; r++) {
  for (let c = 0; c < COLS; c++) {
    circle(LEFT + c * SP, TOP + r * SP, 20);
  }
}

Where the color goes TODO 3

for (let r = 0; r < ROWS; r++) {
  fill(255, 60 + r * 25, 60);  // once per row
  for (let c = 0; c < COLS; c++) {
    circle(…);
  }
}

A row color only needs r, so it can sit in the outer loop. A color that uses c has to go in the inner loop.

COUNTERSReset bulbs = 0 at the top of the function, outside both loops. Inside the outer loop, it would only count the last row.

The inner loop can use r TRIANGLES

for (let r = 0; r < 8; r++) {
  for (let c = 0; c <= r; c++) {
    circle(400 - r * 20 + c * 40, 100 + r * 40, 20);
  }
}

Row r has r + 1 bulbs: a Christmas tree. Total: 1 + 2 + … + 8 = 36.

Drifting snow TODO 5

frameCount % 100 counts 0, 1, … 99, then wraps to 0. Adding it to every y moves the whole grid down 100 pixels, then jumps it back — which looks like steady falling.
