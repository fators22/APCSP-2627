Unit 3: Iteration and Algorithms

Use loops to repeat code in p5.js: while loops, for loops, nested loops, and loops combined with conditionals. Then design, trace, and debug algorithms.

Learning goals

  • Write while loops that repeat until a condition becomes false.
  • Write for loops with a start, condition, and update.
  • Use the loop variable to change position, size, or color on each repetition.
  • Use nested loops to draw rows and grids.
  • Combine loops with if statements to make choices on each repetition.
  • Describe an algorithm using sequencing, selection, and iteration.
  • Trace loops by hand, and find and fix off-by-one and infinite-loop errors.
