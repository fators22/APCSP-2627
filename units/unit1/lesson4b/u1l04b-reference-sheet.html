Writing a variable

let headY = 190;
//  \__/   \___/   \_/
//  make   the     what goes
//  a name name    in it

Use one when

  • the number has to change while the sketch runs
  • the same number appears in several places

Where it goes

  • let at the top, outside draw()
  • changing it goes inside draw()

mouseX and mouseY

Two variables p5 already made. They hold where the cursor is right now, updated before every frame.

circle(mouseX, mouseY, 40);
You only read them. p5 writes them. A variable you made and one p5 made are the same idea — a name for a number — they just have different owners.

Moving a whole object

Pick one point. Write every other part as a distance from it — left or right, up or down.

rect(mouseX,      mouseY,      60, 24);
rect(mouseX - 48, mouseY - 14, 40,  6);
rect(mouseX + 48, mouseY - 14, 40,  6);
circle(mouseX,    mouseY + 18, 16);

Only positions move. Sizes never do. 60, 24, 40, 6 stay exactly as they are. A drone does not get bigger when it flies right — if yours stretches sideways, you converted a size by mistake.
Check it in the corners. Near the middle of the canvas, a part that is twenty pixels off still looks about right. Move the mouse into all four corners — anything left behind still has a fixed number.

On the AP exam

What you write

let y = 100;
y = y + 1;

Exam Reference Sheet

y ← 100
y ← y + 1
The AP exam is not written in JavaScript. It uses College Board's own notation, and the arrow ← means becomes — the same word we use for =. No let, no semicolon.
