Unit 5: Procedures and Parameters

Write your own functions in p5.js: functions that draw, functions that return a value, functions with parameters, and functions that take parameters and return a value. Then use local and global scope correctly.

Learning goals

  • Define a function with a name, parentheses, and a body, and call it from setup() or draw().
  • Explain how a function call jumps to the definition, runs the body, and returns to where it was called.
  • Write a function that uses return to send a value back, and store or use that return value.
  • Write a function with parameters, and tell the difference between a parameter and an argument.
  • Write a function that takes parameters and returns a value.
  • Classify built-in p5.js functions (noStroke(), millis(), fill(255), random(255)) by whether they take parameters and return a value.
  • Explain local and global scope, and predict when a variable can or cannot be used.
  • Use functions as abstraction to remove repeated code and make programs easier to read and fix.
