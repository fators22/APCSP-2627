# AP CSP 2026–27

Class website: https://fators22.github.io/APCSP-2627/

## Updating the site
- **This week:** edit the `#this-week` section in `index.html`.
- **New unit:** copy `units/unit2/` to `units/unit3/`, edit it, then in `index.html` remove `class="locked"` (and the `tabindex`/`aria-disabled`) from that unit's `<li>` and set its `href` to `units/unit3/`.
- **New sketch:** copy `sketches/bouncing-ball/` to a new folder, replace `sketch.js`, and copy a `.sketch` block in `index.html`.
- **Files:** put PDFs in `resources/` and link them as `resources/name.pdf`.
- **Colors/fonts:** change the variables at the top of `style.css`.
